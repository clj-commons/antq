= Quiet SLF4J logger warnings
// lib-version is auto-updated by publish workflow
:lib-version: 2.11.1276
:slf4j-version: 2.0.20

Antq uses Clojure's tools.deps library, which uses Maven libraries that sometimes log.
It is not antq's place to specify a logger, so, depending on your your project, you may see the following messages when antq is run:

[source,text]
----
SLF4J: Failed to load class "org.slf4j.impl.StaticLoggerBinder".
SLF4J: Defaulting to no-operation (NOP) logger implementation
SLF4J: See http://www.slf4j.org/codes.html#StaticLoggerBinder for further details.
----

You can avoid these messages by specifying a logger.

Add the NOP logger to suppress all logging output:
[source,clojure,subs="attributes+"]
----
org.slf4j/slf4j-nop {:mvn/version "{slf4j-version}"}
----

Or add the simple logger that will log to stdout:
[source,clojure,subs="attributes+"]
----
org.slf4j/slf4j-simple {:mvn/version "{slf4j-version}"}
----

TIP: Replace SLF4J version `{slf4j-version}` with the latest released version.

This logger dependency should be added in the context which antq runs, for example, for link:../README.adoc#usage-clojure-cli[`deps.edn`] this would look like:

[source,clojure,subs="attributes+"]
----
{
 :aliases
 {:outdated {:deps {org.slf4j/slf4j-simple {:mvn/version "{slf4j-version}"}
                    com.github.liquidz/antq {:mvn/version "{lib-version}"}}
             :main-opts ["-m" "antq.core"]}}
}
----
