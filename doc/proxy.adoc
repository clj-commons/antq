= Running behind a proxy

Antq uses the proxy settings defined in `~/.m2/settings.xml`.

To run Antq behind a proxy, add a proxy setting like this:

E.g.
[source,xml]
----
<settings>
  <proxies>
    <proxy>
      <id>testproxy</id>
      <active>true</active>
      <protocol>https</protocol>
      <host>localhost</host>
      <port>3128</port>
      <username>foo</username>
      <password>bar</password>
    </proxy>
  </proxies>
</settings>
----
