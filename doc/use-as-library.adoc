= Using `antq` as a library

`antq` is a tool to point out your outdated dependencies, but you can also use it as a library.

== antq.api

The https://cljdoc.org/d/com.github.liquidz/antq/CURRENT/api/antq.api[`antq.api`] namespace is our only supported public API when using `antq` as library. It exposes the following functions:

* `outdated-deps`
** Returns a map of outdated dependencies
* `upgrade-deps!`
** Upgrades version strings in specified files.
