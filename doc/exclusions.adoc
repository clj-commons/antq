= Excluding dependencies

When you'd like to exclude specific dependencies from being checked by Antq, you can use the link:../README.adoc#opt-exclude[--exclude] option.
Alternatively, you can add `:antq/exclude` metadata directly in a supported project file as described below.

== Exclude a dependency

Use `:antq/exclude` metadata to exclude a specific dependency from being checked.

=== deps.edn

[source,clojure]
----
{:deps {foo/bar ^:antq/exclude {:mvn/version "..."}}}
----

=== shadow-cljs.edn

[source,clojure]
----
{:dependencies [^:antq/exclude [foo/bar "..."]]}
----

=== project.clj

[source,clojure]
----
(defproject foo "0.1.0-SNAPSHOT"
  :dependencies [^:antq/exclude [foo/bar "..."]])
----

=== build.boot

[source,clojure]
----
(set-env!
  :dependencies '[^:antq/exclude [foo/bar "..."]])
----

=== bb.edn

[source,clojure]
----
{:deps {foo/bar ^:antq/exclude {:mvn/version "..."}}}
----

== Exclude version(s) of a dependency

To exclude specific versions, replace `^:antq/exclude` (shown above) with one of these forms:

[source,clojure]
----
;; Specific version(s)
^{:antq/exclude "1.2.3"}
^{:antq/exclude ["1.2.3" "1.2.4"]}

;; Version range(s)
^{:antq/exclude "1.2.x"}
^{:antq/exclude ["1.2.x" "1.3.x"]}
----

=== Supported version ranges

[cols="10a,40a,50a"]
|===
| Range | Example | Description

| `.x`
| `1.2.x`
| Matches `1.2.0`, `1.2.1`, etc.

| `*`
| `1.2.0-alpha*`
| Matches `1.2.0-alpha1`, `1.2.0-alpha2`, etc.

|===
