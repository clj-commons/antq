= `antq` on projects that use an old version of Clojure
// lib-version is auto-updated by publish workflow
:lib-version: 2.11.1276

`antq` requires a minimum of Clojure v1.11.
You can still use `antq` on projects that use an older version of Clojure by following the steps below.

== Clojure CLI

Use `:deps`, not `:extra-deps`.
This will use the default Clojure CLI version, instead of the older Clojure version on which your project depends.

TIP: This assumes your installed Clojure CLI version is 1.11 or later.

[source,clojure,subs="attributes+"]
----
{:aliases {:outdated {:deps {com.github.liquidz/antq {:mvn/version "{lib-version}"}}
                      :main-opts ["-m" "antq.core"]}}}
----

If you must use `:extra-deps`, add an `antq` supported version of Clojure explicitly in an alias that uses `antq` as follows.

[source,clojure,subs="attributes+"]
----
{:aliases {:outdated {:extra-deps {;; Use 1.11 or later only for antq
                                   org.clojure/clojure {:mvn/version "1.12.6"}
                                   com.github.liquidz/antq {:mvn/version "{lib-version}"}}
                      :main-opts ["-m" "antq.core"]}}}
----

Then, run `clojure -M:outdated`.

== Leiningen

You can run `antq` as a plugin.
Running as a plugin will ignore the Clojure version on which your project depends.

[source,clojure,subs="attributes+"]
----
 :plugins [[com.github.liquidz/antq "{lib-version}"]]
 ;; optional - you can add antq options here:
 :antq {}
----

Then, run `lein antq`.
